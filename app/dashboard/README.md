# Alzheimer's Detection Dashboard

Web-based UI for visualizing predictions and model explainability

## Features
- Upload MRI scans for prediction
- View classification results with confidence scores
- Visualize Grad-CAM attention maps
- Access model performance metrics
- Batch processing capabilities

## Technologies
- Frontend: React/Vue.js
- Backend: FastAPI (see ../api/main.py)
- Visualization: Plotly, Three.js for 3D rendering

## Setup
```bash
npm install
npm start
```
